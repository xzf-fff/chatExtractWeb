Keep only some conversations

chat-demo's import replaces everything rather than appending. To end up with three conversations, the package must contain exactly those three — this is the full workflow.

Why not import the export as-is

Two reasons stack up:

  1. Import replaces: the demo clears local conversations and writes what is in the package, so the package size becomes your library size.
  2. The index must match: its id set has to equal the packaged chat_sessions/*.json. Keeping a few conversations means pruning both files and index.

Preparation

  • Get the ZIP from DeepSeek's “Settings → Data → Export”; zipped or unzipped both work.
  • If the demo already holds conversations you need, export them first — the import overwrites.
  • Use the latest Chrome or Edge (Safari cannot pick folders).

Six steps

  1. Load: open the subset extractor and drop the folder or ZIP (or use the buttons). The header then shows “N conversations · M images”.
  2. Search: filter titles case- and width-insensitively (/ focuses the box); sort by recency, message count or title; filter by images, duplicate titles or selection.
  3. Preview: open a conversation to check the text, thinking steps and images.
  4. Select: tick the checkbox on each row. “Select all / Invert / Clear” apply to the current filter result.
  5. Validate: the footer shows live status. Errors block export and name the conversation; warnings let you continue.
  6. Export: click “Generate ZIP”; the tool re-parses the result (first entry, order, CRC, index consistency) and only then offers the download.

Three traps

  • Duplicate titles: several conversations may share a title; they all appear, distinguished by update time. Tick only the one you want.
  • Conversations with images: attachments must be packed with the session or images break after import. Filter by “images” to spot them.
  • Size: the more you tick the bigger the ZIP; the footer shows the running total. A few dozen screenshot-heavy conversations can easily reach tens of MB.

Import into chat-demo

  1. Open the official chat-demo: deepseek-ai.github.io/chat-demo;
  2. go to “Settings → Data → Import history” and pick the ZIP;
  3. after importing, check the count matches your selection and that images render.

Why not prune by hand

By hand you must keep manifest.json first, prune the index to match the session files, rewrite the ZIP in the right order, keep every attachment path byte-identical, and keep timestamps and role/status enums valid. Miss one and you get a generic “incomplete content”. See the export structure and troubleshooting.
