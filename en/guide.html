Setup and loading

The tools run entirely in your browser. No installation or account is required. Latest Chrome or Edge recommended.

A DeepSeek export looks roughly like this. The tools only need the index, session JSON files and attachment folders.

deepseek_data-YYYY-MM-DD/
├── manifest.json
├── user.json                  # 可选 / optional
├── chat_session_index.json
├── chat_sessions/
│   ├── <session-id>.json
│   └── <session-id>_files/    # 图片等附件 / attachments

Load data by dropping a folder, dropping a ZIP, or using the buttons. The root must contain chat_session_index.json.

Tip: if a ZIP fails to read (unsupported compression, for example), unzip it and drop the folder instead.

Extract a subset

Open the subset extractor, load the full export, then:

  1. Filter by title (shortcut /); sort by recency, message count or title.
  2. Click a title to preview messages, thinking steps, search cards and image thumbnails.
  3. Check conversations to keep, or batch-select after filtering by images, duplicate titles or selection.
  4. Check the validation state, click “Generate ZIP”, then click again to download.

“Include account info” is off by default. Turning it on adds user.json (account id and masked phone number) to the ZIP.

Merge two versions

If the same conversation was exported twice, both files share conversation and message ids, but text may have changed. Open the version merger, load both exports (A and B), and open a conversation to compare.

Item Rule
Grouping By conversation id; files with the same id are versions of one conversation.
Message alignment By message id; if ids were renumbered between exports (deleting messages shifts later ids), the tool first aligns the role + text sequences and normalizes ids. Identical content reuses the newer version's full fields.
Conflicts Same id but different role, parent_id or fragments. Timestamp or token differences alone are not conflicts.
Single-side messages Messages present in only one version are kept automatically.
Branches All messages are written; only current_message_id points at the leaf you choose.
Times and index inserted_at takes the earliest, updated_at the latest, and message_count is recomputed.
Attachments Union of all versions; the same path prefers the newer version.

Without real data, click “Load the built-in sample” in the empty list: A is older, B is newer, message 3 is the only conflict, 6 → 7 is a second branch, and attachments differ. Changing the selection, a conflict choice or the current branch invalidates the previously generated package.

Import into chat-demo

The ZIP layout is fixed: manifest.json → user.json (optional) → conversation JSON → chat_session_index.json → attachments. The demo parser requires this order; otherwise it reports an incomplete file.

  1. Open the official chat-demo: https://deepseek-ai.github.io/chat-demo/.
  2. Go to “Settings → Data → Import history” and pick the ZIP.
  3. After importing, check the list: only your selected or merged conversations should appear, and images should open.
Warning: importing replaces every conversation and attachment in the demo. Back up first via “Export all history”.

Privacy and data

  • Your data is never uploaded: parsing, merging and packing happen in memory. The page embeds Google AdSense, which only requests ads from Google (and may use cookies); it has no access to the files you select.
  • Generated ZIPs contain full text and images, possibly personal data. Share carefully.
  • Both web tools skip user.json by default; enable it only when needed.

The full policy, including ads, cookies and opt-out options, is on the privacy policy page.

FAQ

Which export formats are supported?

DeepSeek exports with export_format_version: 3. ZIPs must use Store or Deflate; ZIP64 and encrypted archives are not supported, so unzip first.

Why did the message count grow after merging?

The merge keeps the union: messages from only one version and messages on unselected branches are preserved, so the count can exceed either version.

Does it work on mobile?

The layout is responsive, but picking files and previewing images is easier on desktop.
