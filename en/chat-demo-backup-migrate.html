Backing up and migrating chat-demo data

chat-demo stores conversations in the browser you are using, not in an account. Before switching machines, switching browsers or clearing site data, export a ZIP.

Where the data lives

  • chat-demo is a static front-end; data lives in this browser's local storage (typically IndexedDB).
  • It is unrelated to your DeepSeek account's cloud conversations — imports, deletions and clearing affect only this browser.
  • Nothing is shared across browsers or devices, and incognito windows drop everything on close.

How to back up

  1. open chat-demo, go to “Settings → Data”;
  2. click “Export all history” to get a ZIP with the same structure as an official export;
  3. keep it in a local folder (or trusted storage if you need it on another device — see the last section).

Suggested rhythm: before any large import, once a month, and before switching devices. Backups are cheap, data loss is not.

How to restore

  1. open the same chat-demo URL on the new device or browser;
  2. “Settings → Data → Import history”, pick the backup ZIP;
  3. check the conversation count and that images render.

Import replaces everything: whatever is already in the target browser is wiped first. Always back up before importing.

When data is lost

  • clearing “site data / cookies and site data”;
  • switching browser or device (storage is separate);
  • using incognito or private windows;
  • importing another ZIP (overwrites);
  • low storage, or a browser configured to clear data on exit.

Finer-grained backups

  • Keep only part of it: use the subset extractor to pull out the conversations you need — much smaller.
  • Merge two backups: the version merger aligns by message and unions them (see merging exports).
  • To confirm a backup is intact, import it into another browser once.

Storing safely

A backup ZIP contains your full conversations and images (often screenshots) — it is a complete chat archive. Encrypt it before uploading to a cloud drive, set link expiry, and never post it to public groups or repositories. See local vs cloud and the privacy policy.
