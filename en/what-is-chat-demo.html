What is chat-demo?

It is DeepSeek's open-source “API usage demo”, a static website. The ZIP we produce is imported there — so it's worth knowing what it does and doesn't do.

What it is

  • An open-source project in DeepSeek's official deepseek-ai/chat-demo repo, MIT licensed, a pure static site;
  • official deployment: deepseek-ai.github.io/chat-demo;
  • It demonstrates the API's chat capability, and its data lives in your current browser; the official repo is the reference for details.

Why it matters for exports

Your real account data lives in the cloud; the export is a ZIP. chat-demo offers a way to load such a ZIP back into a UI via “Settings → Data → Import history”, which is also the most direct way to verify that a package is valid: if it imports, the structure and fields are right.

How to import

  1. open the official chat-demo;
  2. go to “Settings → Data → Import history”;
  3. pick the ZIP and confirm;
  4. check that the list count matches the package and that images render.

Import replaces everything: it clears the demo's existing conversations and attachments, then writes the package contents. Export your current history inside the demo first.

Three package rules it enforces

  1. manifest.json must be the first entry (holding {"export_format_version":3});
  2. the index's id set must exactly equal the packaged chat_sessions/*.json;
  3. fixed order: manifest → user.json (optional) → sessions → index → attachments.

Details in the export structure article; error handling in troubleshooting.

What it can't do

  • it does not touch your account's cloud conversations — the import is browser-local;
  • it is not a replacement for the official app and has no account sync;
  • clearing browser data (or switching browsers) loses imported conversations — keep the ZIP if you need them long-term.

Three questions

  • Fewer conversations after import? Nothing was lost: the package only had those. Import replaces.
  • Images missing? Attachments weren't packaged or export_path doesn't match — see images and attachments.
  • Import failed? Check the four errors in troubleshooting; most are package-structure issues.
