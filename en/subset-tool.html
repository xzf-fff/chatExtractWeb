校验明细

如何在 chat-demo 中验证

  1. 点右上「生成 ZIP」，完成后点「下载」保存到本地（默认文件名 deepseek_subset_*.zip）。
  2. 打开官方 chat-demo：https://deepseek-ai.github.io/chat-demo/。
  3. 进入 设置 → 数据管理 → 导入历史对话，选择刚下载的 ZIP，确认导入。
  4. 左侧会话列表应只出现你勾选的对话，点开确认图片正常显示。

注意：导入会覆盖 demo 本地全部对话与附件。若 demo 里已有需要保留的对话，请先在其中「导出所有历史对话」备份。

下载的 ZIP 包含完整对话正文与图片，请谨慎分享或上传到公共空间。

生成的 ZIP 结构：manifest.json（首条目）→ 会话 JSON → chat_session_index.json → 图片附件。这个顺序是 demo 导入解析器要求的，顺序错误会报「文件内容不完整」。

推荐使用 Chrome / Edge 最新版：Safari 不支持选择本地文件夹，部分浏览器缺少解压能力，可把导出 ZIP 解压后拖入文件夹/ZIP 再试。
