My export is huge

A few hundred conversations easily reach tens of MB, and the bulk is images rather than text. To shrink it you first need to know where the weight is.

Where the size goes

An export holds three kinds of content:

  • Session JSON: plain text; a few hundred conversations amount to a few MB, less after compression.
  • Attachments (images): usually the dominant cost. Screenshots are stored at full resolution; 0.3–1 MB each is normal.
  • Index and manifest: negligible, tens of KB.

Rule of thumb: image-bearing conversations are often a single-digit percentage of the total, yet account for over 80% of the bytes.

Three effective moves

  1. Select only what you need — the only large lever that exists. Import replaces everything anyway, so unneeded conversations just add weight.
  2. See which conversations carry images: filter by “images” and drop the unimportant ones — often halves the package in one pass.
  3. Leave account info out: user.json is small but identifies your account; it is off by default.

What wastes effort or breaks the package

  • Re-zipping with the OS archiver: images are already compressed, so you save almost nothing while reordering ZIP entries → “unrecognized file”.
  • Batch re-compressing images: changes bytes and can disagree with the recorded dimensions/size, adding risk for little gain — dropping those conversations is simpler.
  • Deleting attachment files by hand: export_path still points at them, so every image breaks (see corrupt attachment).

How big is too big

Tens of MB is normal and the browser handles it fine. The concern starts at hundreds of MB: everything is processed in memory, and very large packages can make the tab sluggish or crash. If you only need a few conversations, don't import the whole archive.

Steps

  1. open the subset extractor and load the full export;
  2. filter by “images” to see which conversations are heaviest;
  3. search for the ones you actually need, tick them, clear the rest;
  4. the footer shows the running size — check it is acceptable;
  5. generate the ZIP, let the self-check pass, download.
