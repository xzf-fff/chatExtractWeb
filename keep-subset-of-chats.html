只保留部分对话并导入 chat-demoKeep only some conversations

chat-demo 的导入是「整包替换」，不是「追加」。想要 3 组对话，包内就必须只有 3 组——这篇是从全量导出裁出子集的完整流程。chat-demo's import replaces everything rather than appending. To end up with three conversations, the package must contain exactly those three — this is the full workflow.

为什么不能直接导入原始导出Why not import the export as-is

两个原因叠在一起：Two reasons stack up:

  1. 导入会覆盖：chat-demo 导入时会清掉本地已有对话，再写入包内的；所以包里有多少组，导入后就有多少组。Import replaces: the demo clears local conversations and writes what is in the package, so the package size becomes your library size.
  2. 索引必须一致：包内索引的会话 id 集合必须与 chat_sessions/*.json 完全相等。想只留几组，就必须同时裁会话文件和索引。The index must match: its id set has to equal the packaged chat_sessions/*.json. Keeping a few conversations means pruning both files and index.

准备工作Preparation

  • 从 DeepSeek 的「设置 → 数据管理 → 导出」拿到 ZIP，解压与否都可以（工具两种都能读）。Get the ZIP from DeepSeek's “Settings → Data → Export”; zipped or unzipped both work.
  • 如果你想保留 demo 里现有对话，先在 demo 里「导出所有历史对话」备份——导入会覆盖。If the demo already holds conversations you need, export them first — the import overwrites.
  • 浏览器用 Chrome / Edge 最新版（Safari 不支持选择本地文件夹）。Use the latest Chrome or Edge (Safari cannot pick folders).

六步走完Six steps

  1. 载入：打开 子集提取器，把导出文件夹或 ZIP 拖进页面（或点右上角按钮）。载入成功后顶部会显示「N 组对话 · M 张图片」。Load: open the subset extractor and drop the folder or ZIP (or use the buttons). The header then shows “N conversations · M images”.
  2. 检索：搜索框按标题过滤（忽略大小写、全半角与多余空格，快捷键 /）；可按最近更新 / 消息数 / 标题排序；可按「带图片 / 重名 / 已选」筛选。Search: filter titles case- and width-insensitively (/ focuses the box); sort by recency, message count or title; filter by images, duplicate titles or selection.
  3. 预览：点标题看正文、思考过程与图片，确认是不是你要的那一组。Preview: open a conversation to check the text, thinking steps and images.
  4. 勾选：点行首方框选中。表头的「全选当前 / 反选 / 清空」只作用于**当前筛选结果**。Select: tick the checkbox on each row. “Select all / Invert / Clear” apply to the current filter result.
  5. 校验：底部实时显示状态。错误会阻止导出并指出具体会话；警告可以继续。Validate: the footer shows live status. Errors block export and name the conversation; warnings let you continue.
  6. 导出：点「生成 ZIP」，工具会在浏览器里复解析成品做自检（首条目、顺序、CRC、索引一致性），通过后再点一次下载。Export: click “Generate ZIP”; the tool re-parses the result (first entry, order, CRC, index consistency) and only then offers the download.

三个易错点Three traps

  • 同名标题：数据里存在多组同名对话（例如都叫「SFTP使用指南」），列表会全部列出，用更新时间区分；只想要其中一条就单独勾那个。Duplicate titles: several conversations may share a title; they all appear, distinguished by update time. Tick only the one you want.
  • 带图片的会话：附件必须跟会话一起打包，否则导入后图片全裂。可以先用「带图片」筛选确认哪些会话有附件。Conversations with images: attachments must be packed with the session or images break after import. Filter by “images” to spot them.
  • 体积：勾得越多包越大，底部会实时算已选体积；几十组带截图的对话很容易到几十 MB。Size: the more you tick the bigger the ZIP; the footer shows the running total. A few dozen screenshot-heavy conversations can easily reach tens of MB.

导入 chat-demoImport into chat-demo

  1. 打开官方 chat-demo：deepseek-ai.github.io/chat-demo；Open the official chat-demo: deepseek-ai.github.io/chat-demo;
  2. 进入「设置 → 数据管理 → 导入历史对话」，选刚下载的 ZIP；go to “Settings → Data → Import history” and pick the ZIP;
  3. 导入后核对：会话数量应与你勾选的一致，点开确认图片正常显示。after importing, check the count matches your selection and that images render.

手工裁剪为什么不建议Why not prune by hand

要手工做对，你必须同时：让 manifest.json 留在第一位、把索引裁到与会话文件一致、按正确顺序重写 ZIP、保持附件路径逐字不变、维持时间戳与 role/status 枚举合法。任何一步出错，chat-demo 只会回一句笼统的「文件内容不完整」。具体约束见 导出包结构详解 与 报错排查。By hand you must keep manifest.json first, prune the index to match the session files, rewrite the ZIP in the right order, keep every attachment path byte-identical, and keep timestamps and role/status enums valid. Miss one and you get a generic “incomplete content”. See the export structure and troubleshooting.
