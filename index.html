为什么需要重新打包Why repackaging is required

chat-demo 的导入器对包结构有硬性要求，直接导入原始数据或手改 ZIP 很容易失败。The chat-demo importer enforces strict package rules; editing a ZIP by hand usually fails.

索引必须与文件一致Index must match files

索引里的会话 id 集合必须与包内会话文件完全相等，多一个少一个都会导入失败。The ids in the index must exactly match the packaged conversation files.

条目顺序是硬约束Entry order is mandatory

manifest 必须是第一个条目，索引排在全部会话之后，附件排在索引之后。manifest first, then conversations, then the index, then attachments.

导入前先校验Validated before download

时间格式、消息分支、枚举值、CRC 与索引一致性都会检查，不通过就不产出半成品。Timestamps, branch links, enums, CRC and index consistency are checked before a ZIP is produced.

三步完成Three steps

两个工具的流程一致，只是中间一步不同。Both tools work the same way; only the middle step differs.

载入导出Load the export

拖入文件夹或 ZIP，或点按钮选择。只需包含 chat_session_index.json 与 chat_sessions/。Drop a folder or ZIP, or use the buttons. It only needs chat_session_index.json and chat_sessions/.

挑选或解决冲突Select or resolve

按标题勾选要保留的对话；合并时逐条选择冲突保留哪一版，并确认当前分支。Check the conversations to keep; when merging, pick a version per conflict and confirm the current branch.

导出并导入 demoExport and import

生成 ZIP 后自检，再把包导入 chat-demo 验证。导入会覆盖本地对话，先备份。Generate and self-check the ZIP, then import it into chat-demo. Import overwrites local data, so back up first.

常见问题FAQ

对话数据会上传到服务器吗？Is my data uploaded anywhere?

不会。ZIP 解析、合并与打包全部在浏览器内存中完成，对话文件不会被上传到任何服务器。页面嵌入了 Google AdSense 广告脚本，它会向 Google 请求广告（可能使用 Cookie），但接触不到你选择的文件。No. Parsing, merging and packing all happen in browser memory; your files are never uploaded. The page embeds Google AdSense, which requests ads from Google (and may use cookies) but has no access to the files you select.

为什么不能直接把原始导出包导入 chat-demo？Why can't I import the original export directly?

导入会覆盖 demo 本地全部对话，并要求 manifest.json 是第一个条目、索引中的会话 id 与包内会话文件完全一致。只想保留部分对话时，必须同时裁剪会话文件与索引。Import replaces every conversation in the demo and requires manifest.json to be the first entry, with the index ids matching the packaged conversation files exactly. Keeping a subset means pruning both files and index.

导入会覆盖 demo 里已有的对话吗？Will importing overwrite my demo data?

会。导入前请在 demo 中执行“导出所有历史对话”做一次备份。Yes. Back up first with “Export all history” in the demo.

支持 Safari 吗？Does it work in Safari?

推荐 Chrome / Edge 最新版。Safari 不支持选择本地文件夹，部分浏览器也缺少解压能力；遇到问题可把导出 ZIP 解压后拖入文件夹。Latest Chrome / Edge recommended. Safari cannot pick local folders and some browsers lack unzip support; unzip the export and drop the folder if reading fails.

需要安装或联网吗？Do I need to install anything?

不需要安装。工具是静态页面，可以部署后在线使用，也可以直接下载到本地双击打开。No installation. The tools are static pages you can host or open locally.
