chat-demo 的数据怎么备份与迁移Backing up and migrating chat-demo data

chat-demo 的对话存在**你当前这个浏览器**里，不跟任何账号走。换电脑、换浏览器、清理网站数据之前，先导出一份 ZIP。chat-demo stores conversations in the browser you are using, not in an account. Before switching machines, switching browsers or clearing site data, export a ZIP.

数据存在哪Where the data lives

  • chat-demo 是纯前端静态站，数据保存在**当前浏览器的本地存储**里（通常是 IndexedDB）。chat-demo is a static front-end; data lives in this browser's local storage (typically IndexedDB).
  • 它不等同于你 DeepSeek 账号里的云端对话——导入、删除、清理都只影响当前浏览器。It is unrelated to your DeepSeek account's cloud conversations — imports, deletions and clearing affect only this browser.
  • 不同浏览器、不同设备之间**不共享**；无痕窗口关闭即清空。Nothing is shared across browsers or devices, and incognito windows drop everything on close.

怎么备份How to back up

  1. 打开 chat-demo，进入「设置 → 数据管理」；open chat-demo, go to “Settings → Data”;
  2. 点「导出所有历史对话」，得到一个 ZIP（结构与 DeepSeek 官方导出一致）；click “Export all history” to get a ZIP with the same structure as an official export;
  3. 把 ZIP 存到本地文件夹（需要跨设备就放到你信任的存储，见最后一节）。keep it in a local folder (or trusted storage if you need it on another device — see the last section).

建议节奏：**每次大批导入前**、**每月一次**、**换设备前**各备份一次。备份成本很低，丢数据成本很高。Suggested rhythm: before any large import, once a month, and before switching devices. Backups are cheap, data loss is not.

怎么迁移恢复How to restore

  1. 在新设备/新浏览器打开同一个 chat-demo 地址；open the same chat-demo URL on the new device or browser;
  2. 「设置 → 数据管理 → 导入历史对话」，选择备份的 ZIP；“Settings → Data → Import history”, pick the backup ZIP;
  3. 核对会话数量与图片是否正常。check the conversation count and that images render.

导入是整包替换：如果目标浏览器里已经有对话，会先被清空。所以「先备份，再导入」是必须的顺序。Import replaces everything: whatever is already in the target browser is wiped first. Always back up before importing.

什么时候会丢数据When data is lost

  • 清理浏览器「网站数据 / Cookie 及网站数据」；clearing “site data / cookies and site data”;
  • 换浏览器或换设备（存储不互通）；switching browser or device (storage is separate);
  • 使用无痕/隐私窗口；using incognito or private windows;
  • 导入一个新的 ZIP（覆盖）；importing another ZIP (overwrites);
  • 浏览器处于空间不足或「退出时清除数据」的设置下。low storage, or a browser configured to clear data on exit.

用工具做更细的备份Finer-grained backups

  • 只想保留一部分：用 子集提取器 从备份 ZIP 里挑出需要的会话，体积更小。Keep only part of it: use the subset extractor to pull out the conversations you need — much smaller.
  • 两次备份需要合并：用 版本合并器 按消息对齐取并集（见 合并两次导出）。Merge two backups: the version merger aligns by message and unions them (see merging exports).
  • 想确认备份包本身没坏：导入到另一个浏览器验证一次即可。To confirm a backup is intact, import it into another browser once.

存放注意Storing safely

备份 ZIP 里有完整对话和你上传过的图片（常含截图），等同于一份聊天记录存档。放网盘前建议先加密压缩、链接设有效期；不要把备份传到公共群或公开仓库。详见 本地 vs 网盘 与 隐私政策。A backup ZIP contains your full conversations and images (often screenshots) — it is a complete chat archive. Encrypt it before uploading to a cloud drive, set link expiry, and never post it to public groups or repositories. See local vs cloud and the privacy policy.
