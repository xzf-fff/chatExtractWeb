准备与载入Setup and loading

工具完全在浏览器里运行，不需要安装，也不需要账号。推荐使用最新版 Chrome 或 Edge。The tools run entirely in your browser. No installation or account is required. Latest Chrome or Edge recommended.

DeepSeek 导出的目录结构大致如下，工具只依赖其中的索引、会话 JSON 与附件目录：A DeepSeek export looks roughly like this. The tools only need the index, session JSON files and attachment folders.

deepseek_data-YYYY-MM-DD/
├── manifest.json
├── user.json                  # 可选 / optional
├── chat_session_index.json
├── chat_sessions/
│   ├── <session-id>.json
│   └── <session-id>_files/    # 图片等附件 / attachments

载入方式有三种：把文件夹拖进页面、把 ZIP 拖进页面、或点右上角按钮选择。每份数据的根目录必须能找到 chat_session_index.json。Load data by dropping a folder, dropping a ZIP, or using the buttons. The root must contain chat_session_index.json.

提示：如果 ZIP 读取失败（例如压缩方式不受支持），先解压，再把文件夹拖进来。 Tip: if a ZIP fails to read (unsupported compression, for example), unzip it and drop the folder instead.

提取对话子集Extract a subset

打开 子集提取器，载入全量导出后：Open the subset extractor, load the full export, then:

  1. 用搜索框按标题过滤（快捷键 /），可按最近更新、消息数或标题排序。Filter by title (shortcut /); sort by recency, message count or title.
  2. 点标题打开预览：消息气泡、思考过程、搜索结果卡片与图片缩略图。Click a title to preview messages, thinking steps, search cards and image thumbnails.
  3. 勾选要保留的对话，或按「带图片 / 重名 / 已选」筛选后批量选择。Check conversations to keep, or batch-select after filtering by images, duplicate titles or selection.
  4. 底部确认校验状态，点「生成 ZIP」，再点一次按钮下载。Check the validation state, click “Generate ZIP”, then click again to download.

「包含账号信息」默认关闭。开启后会把 user.json 打进包内，其中含账号标识与脱敏手机号，分享前请确认。“Include account info” is off by default. Turning it on adds user.json (account id and masked phone number) to the ZIP.

合并两个版本Merge two versions

同一组对话如果导出过两次，两份数据里的会话 id 相同、消息 id 也相同，但正文可能被改过。打开 版本合并器，载入两份导出（标记为 A、B），点开会话即可对比。If the same conversation was exported twice, both files share conversation and message ids, but text may have changed. Open the version merger, load both exports (A and B), and open a conversation to compare.

项目Item 规则Rule
分组Grouping 按会话 id；同一 id 的不同文件视为不同版本。By conversation id; files with the same id are versions of one conversation.
消息对齐Message alignment 按消息 id；两份导出 id 被重排过（删消息后整体前移）时，先用「角色 + 正文」序列对齐归一化 id 再比较；内容相同则复用较新版本的完整字段。By message id; if ids were renumbered between exports (deleting messages shifts later ids), the tool first aligns the role + text sequences and normalizes ids. Identical content reuses the newer version's full fields.
冲突判定Conflicts 同 id 但 role、parent_id 或 fragments 不同。仅时间戳或 token 统计不同不算冲突。Same id but different role, parent_id or fragments. Timestamp or token differences alone are not conflicts.
单侧消息Single-side messages 只在某一版存在的消息自动保留。Messages present in only one version are kept automatically.
分支Branches 所有消息（含未选中分支）都会写入，只有 current_message_id 指向你选的叶子。All messages are written; only current_message_id points at the leaf you choose.
时间与索引Times and index inserted_at 取最早、updated_at 取最晚，message_count 按合并结果重算。inserted_at takes the earliest, updated_at the latest, and message_count is recomputed.
附件Attachments 各版本附件取并集，同路径优先较新版本。Union of all versions; the same path prefers the newer version.

没有真实数据时，点列表空白处的「载入内置示例」：A 是旧版、B 是新版，消息 3 是唯一冲突，6 → 7 是另一条分支，附件也各不相同。改动勾选、冲突选择或当前分支后，之前生成的包会立即失效，需要重新导出。Without real data, click “Load the built-in sample” in the empty list: A is older, B is newer, message 3 is the only conflict, 6 → 7 is a second branch, and attachments differ. Changing the selection, a conflict choice or the current branch invalidates the previously generated package.

导入 chat-demoImport into chat-demo

生成的 ZIP 结构固定为：manifest.json → user.json（可选）→ 会话 JSON → chat_session_index.json → 附件。这个顺序是 demo 解析器要求的，顺序错误会报「文件内容不完整」。The ZIP layout is fixed: manifest.json → user.json (optional) → conversation JSON → chat_session_index.json → attachments. The demo parser requires this order; otherwise it reports an incomplete file.

  1. 打开官方 chat-demo：https://deepseek-ai.github.io/chat-demo/。Open the official chat-demo: https://deepseek-ai.github.io/chat-demo/.
  2. 进入「设置 → 数据管理 → 导入历史对话」，选择刚下载的 ZIP。Go to “Settings → Data → Import history” and pick the ZIP.
  3. 确认导入后检查列表：只应出现你选择或合并的对话，图片能正常打开。After importing, check the list: only your selected or merged conversations should appear, and images should open.
注意：导入会覆盖 demo 本地全部对话与附件。导入前先执行一次「导出所有历史对话」备份。 Warning: importing replaces every conversation and attachment in the demo. Back up first via “Export all history”.

隐私与数据Privacy and data

  • 对话数据不上传：解析、合并、打包全部在浏览器内存中完成，文件不会被发送出去。页面含 Google AdSense 广告脚本，它只负责向 Google 请求广告（可能使用 Cookie），接触不到你选择的文件。Your data is never uploaded: parsing, merging and packing happen in memory. The page embeds Google AdSense, which only requests ads from Google (and may use cookies); it has no access to the files you select.
  • 生成的 ZIP 含完整对话正文与图片，可能包含个人信息，请谨慎分享。Generated ZIPs contain full text and images, possibly personal data. Share carefully.
  • 两个网页工具默认不导出 user.json；需要时再手动开启。Both web tools skip user.json by default; enable it only when needed.

完整的隐私政策（含广告与 Cookie 说明、退出方式）见 隐私政策。The full policy, including ads, cookies and opt-out options, is on the privacy policy page.

常见问题FAQ

工具支持哪些导出格式？Which export formats are supported?

DeepSeek 导出的 export_format_version: 3。ZIP 需为 Store 或 Deflate 压缩；ZIP64 与加密包不支持，请解压后拖入文件夹。DeepSeek exports with export_format_version: 3. ZIPs must use Store or Deflate; ZIP64 and encrypted archives are not supported, so unzip first.

为什么合并后消息变多了？Why did the message count grow after merging?

合并保留了两版的并集：只在某一版出现的消息、未选中分支上的消息都会写入，所以数量可能大于任一单版本。The merge keeps the union: messages from only one version and messages on unselected branches are preserved, so the count can exceed either version.

可以在手机上用吗？Does it work on mobile?

界面做了响应式，但挑选文件与预览大图在桌面浏览器上体验更好。The layout is responsive, but picking files and previewing images is easier on desktop.
